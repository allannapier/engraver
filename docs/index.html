Design it, test it, place it, burn it.

A browser app for the Atomstack A10 and other GRBL diode lasers. A small Python server talks to the laser over USB. Claude Code can draw and set up jobs. Only you can start one.

How a job goes

  1. DesignImport SVGs and pictures, add text and shapes.
  2. TestBurn a test card on scrap and keep the best square.
  3. PlaceSee the real board on the canvas through a webcam.
  4. FrameTrace the outline with the laser off.
  5. BurnCheck the summary and press Start burning.

A canvas that is the bed

The canvas is the bed in millimetres. Every design sits on a layer, and every layer has a mode, speed, power and passes.

  • Line layers trace outlines: score or cut.
  • Fill layers scan back and forth: engrave, solid, dithered or with power varying by shade.
  • Move, scale, rotate, nudge, undo. Designs save in the app with a thumbnail.

Geometry is done in the browser: line layers are traced from the live SVG, fill layers rendered to a bitmap at the layer's line gap.

Settings from your machine, not a forum

Built-in materials are only starting points for a 10 W diode. The test grid burns a labelled card of squares on scrap:

  • Engrave and Score: speed across, power down.
  • Cut: speed against passes. The squares that drop out are cut through.

Click the best square and it's saved to your own library as "picked from a test". Layers apply it from their Presets menu.

See the board before you burn

A USB webcam over the bed puts a corrected photo under the canvas, so designs land on the material you actually have.

  1. Burn or draw four crosses at known spots.
  2. Click each one in a picture from the camera.
  3. The app fits a perspective correction from those four points.

Perspective only, no lens correction yet, so wide lenses are a few mm out near the edges. Photos are never saved.

Laser control that keeps its place

  • Jog in 0.1 to 50 mm steps; set origin on the corner of your material.
  • Frame traces the job's outline, laser off or at a 2 % dot.
  • Start always shows size, time and layers first.
  • Stop holds feed, waits for the head to halt, then resets. Position is kept.

Origin is GRBL's G54 offset (G10 L20), so it survives a power cycle. Jobs run in M4 dynamic power, scaled by the controller's own $30.

Claude Code drives. You press start.

Engraver has no AI built in. While it runs, it's an MCP server, so Claude Code (or any MCP client) can work the app with your own subscription.

It can

  • Draw designs as SVG and line parts up across layers
  • Set layers from your tested materials
  • See the canvas, and a fresh photo of the bed
  • Connect, jog, set the origin, frame, pause and stop

It can't

  • Start or resume a job
  • Send console commands, home or unlock
  • Write to your material library
  • File bug reports

Every change

  • Shows on your canvas as it happens
  • Is one undo step
  • Pops a note naming the client
  • Has its SVG sanitised first

Try: a 90 mm coaster with a mountain line drawing, engraved, with a cut circle around it

Under the hood

  • No build step. FastAPI and pyserial on the server; plain ES modules in the page.
  • Character-counting streaming. Fills GRBL's 128-byte buffer without overrunning it.
  • Loopback only. Requests from other sites are refused by Host and Origin checks.
  • Simulator built in. A fake GRBL to try everything without the laser. CI drives it in Chromium.
  • Bug reports you read first. Diagnostics gathered, secrets scrubbed, full text shown before filing.
  • Tested. pytest on Python 3.11 to 3.14 at 90 % coverage, plus a browser test with a fake camera.

Get started

Run it

Needs uv and Python 3.11+. No laser? Pick Simulator as the port.

git clone https://github.com/allannapier/engraver
cd engraver
uv run engraver

Add it to Claude Code

Keep Engraver open in your browser, then:

claude mcp add --transport http engraver \
  http://127.0.0.1:8642/mcp

Setup → AI assistant shows this with a Copy button. Stdio-only clients can run engraver-mcp.

Safety

A 10 W diode laser blinds and starts fires. Wear goggles rated for 455 nm, ventilate, and never leave a running job. Never laser PVC or vinyl: they release chlorine gas. The software comes with no warranty and replaces nothing about watching the machine.
